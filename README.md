# 🎮 Tic Tac Toe

A classic Tic Tac Toe game built using **HTML, CSS, and JavaScript**.  
No frameworks, no libraries — just pure web fundamentals.

---

## ✨ Features
- 3x3 Tic Tac Toe board
- Two-player mode (Player X vs Player O)
- Win and draw detection
- Simple, clean UI
- Lightweight and runs in any modern browser

---
Navigate into the project folder:

cd Tic-tac-toe

# Run the Game
Simply open the **index.html** file in your browser:

open index.html
(or just double-click it!)

# 🎯 How to Play
Player X always starts first.

Players take turns clicking on empty squares.

The first player to align three marks (row, column, or diagonal) wins.

If all squares are filled and no one wins, it’s a draw.
